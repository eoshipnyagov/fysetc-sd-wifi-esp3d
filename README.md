# FYSETC SD‑WiFi V2.1 · ESP3D для microSD

Компактная прошивка и веб-панель для обычной платы **FYSETC SD‑WiFi V2.1** с ESP8285H16 (2 МБ flash). Панель предназначена для доступа к microSD по Wi‑Fi и настройки сети. Управления принтером в ней нет: SD-слот принтера соединён с платой по SPI, а UART платы выведен на USB-переходник. HTTP-команды G-code отклоняются; терминал WebSocket, макросы G-code, уведомления и управление выводами отключены при сборке.

Основа — [ESP3D 3.1](https://github.com/luc-github/ESP3D) на коммите `b85dc1cce0f87894e524c96f3685fcba48006e67`. Исходные изменения находятся в [`firmware/esp3d-3.1.patch`](firmware/esp3d-3.1.patch), код панели — в [`web/index.html`](web/index.html). Папка `dist` содержит готовые образы.

## Возможности

- Просмотр, загрузка, скачивание, удаление файлов и создание каталогов на **microSD**; также доступ через WebDAV.
- Настройки Wi‑Fi клиента, точки доступа, резервной точки доступа, адреса и WebDAV. Русский интерфейс по умолчанию, английский переключается вверху страницы. Явная кнопка сохранения находится внизу раздела настроек.
- Тёмный интерфейс, адаптированный под телефон. В образе LittleFS лежит только одна сжатая HTML-страница; страницы старой панели с инструментами принтера удалены.
- Пустые файлы `IP_<адрес>.GCO` в режиме клиента или `AP_<адрес>.GCO` в режиме точки доступа показывают адрес в меню файлов Marlin. При защищённой точке доступа дополнительно создаётся `PW_<пароль>.GCO`. Старые пустые маркеры удаляются при смене режима. Недопустимые для FAT символы пароля кодируются как `~HH`.
- Учёт общего SPI-доступа к карте: после активности принтера ESP3D ждёт до 20 секунд, прежде чем обращаться к microSD, и освобождает линии при завершении операции.

**Внимание:** пароль точки доступа виден в имени файла на принтере и по сети. Не используйте для неё пароль, который защищает другие сервисы. Во время печати с microSD не изменяйте файлы по сети.

## Подготовка, сборка и прошивка через COM

В папке `scripts` есть одинаковые скрипты для Windows и Bash:

| Задача | Windows | Bash |
| --- | --- | --- |
| Установить локальные зависимости | `scripts\setup.bat` | `./scripts/setup.sh` |
| Собрать образы | `scripts\build.bat` | `./scripts/build.sh` |
| Записать плату на COM3 | `scripts\flash-com.bat` | `./scripts/flash-com.sh` |
| Записать другой порт | `scripts\flash-com.bat COM7` | `./scripts/flash-com.sh COM7` |

`setup` создаёт `.venv` внутри репозитория и ставит PlatformIO, `esptool` и библиотеки проекта. `build` выдаёт `dist/firmware.bin`, `dist/littlefs.bin` и `dist/index.html.gz`. `flash-com` записывает **оба** образа: прошивку по адресу `0x000000`, веб-интерфейс по `0x1C0000`.

Перед запуском `flash-com` переключите плату в `USB2UART`, отсоедините USB, зажмите `FLSH`, подключите USB и отпустите `FLSH`. Скрипт сам не переводит её в загрузчик. После успешной записи нажмите `RST` без `FLSH`.

Настройки Wi‑Fi ESP3D обычно сохраняются при записи этих двух областей. При первом доступе к microSD после запуска подождите около 20 секунд. Если устройство находится в режиме точки доступа, адрес панели по умолчанию — `http://192.168.0.1/`, SSID `ESP3D`, пароль `12345678`.

## Обновление уже работающей платы по сети

На плате с ESP3D можно загрузить `dist/firmware.bin` через раздел **Обслуживание → Прошивка** или прежний маршрут `/updatefw`. После перезапуска плата сохранит настройки сети. Страницу замените командой:

```powershell
python -m pip install -r requirements.txt
python scripts\install_webui.py 192.168.1.123
```

Замените адрес примером своего IP. Скрипт сначала записывает и сверяет `index.html.gz`, затем удаляет `tool.html` и `esp32cam.html` прежней панели; `preferences.json` не затрагивает. Для проверки без удаления старых страниц укажите `--keep-legacy`. При необходимости доступна встроенная резервная страница ESP3D по `/?forcefallback=yes`.

WebDAV использует порт `8181` по умолчанию: `http://<IP-платы>:8181/`. Текущий адрес платы можно увидеть в меню принтера по имени пустого файла `IP_*.GCO` или `AP_*.GCO`.

## Консоль

При подключении платы к USB в режиме `USB2UART` откройте COM-порт на скорости **115200 бод**. Команды вводятся обычным текстом; `help` выводит тот же список прямо с платы.

```text
help
status
version
restart

wifi show
wifi scan
wifi mode sta
wifi mode ap
wifi sta ssid MyNetwork
wifi sta password MyPassword
wifi ap ssid ESP3D
wifi ap password NewPassword
wifi fallback ap
wifi fallback off

webdav show
webdav on
webdav off
webdav port 8181

sd status
sd ls /
sd exists /file.gcode
sd mkdir /models
sd touch /empty.gcode
sd rm /old.gcode
sd rmdir /empty-folder
```

После изменения Wi‑Fi выполните `restart`. Имена сетей и пароли с пробелами поддерживаются. Путь к файлу SD всегда начинается с `/`. Форматирование SD и сброс настроек намеренно не имеют коротких команд; при необходимости доступны только через старый технический синтаксис ESP3D. Старые команды `[ESP…]` продолжают работать для совместимости с веб-панелью.

## Ручная сборка из исходников

Нужны Git, Python 3.9+ и PlatformIO CLI. Скрипт скачивает точно указанный коммит ESP3D, применяет патч, сжимает `web/index.html` и собирает образы:

```powershell
python -m pip install platformio
python scripts\build.py
```

Результат: `dist/firmware.bin`, `dist/littlefs.bin`, `dist/index.html.gz`. Можно указать `--platformio C:\path\to\pio.exe`. Сборка требует доступ к зависимостям PlatformIO. Содержимое флеш-памяти конкретного устройства, личные сетевые настройки и пароли в репозиторий не входят.

## Проверка и ограничения

Сборка ESP8285 и LittleFS прошла, новая страница проверена на синтаксис JavaScript и сверена с файлом, который отдаёт плата. После обновления на реальной плате проверены чтение списка SD, загрузка/скачивание/удаление тестового файла через HTTP, чтение через WebDAV, создание/удаление каталога и отказ HTTP-командам принтера. Файлы-маркеры проверены на карте, а полное имя IP-маркера — на дисплее Marlin.

На данной 32-гигабайтной карте полный пересчёт занятого места зависал, поэтому он отключён при обновлении списка файлов. Поле занятого места SD может показывать `0 B` и в панели не используется. Если принтер обращается к карте, операции по сети временно недоступны.
